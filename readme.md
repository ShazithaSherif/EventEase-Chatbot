# EventEase-Chatbot
An intelligent chatbot for providing accurate information on college events, announcements, registration, and participation guidelines.

It a simple chatbot application designed to provide information about upcoming events and announcements.

## Features

- View upcoming events
- Get event dates and venues
- Get event descriptions
- Ask questions about specific events
- Interactive chatbot interface

## Technologies Used

- Python
- Streamlit
